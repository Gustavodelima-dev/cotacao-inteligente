# 🧠 Central de Compras Inteligente

Sistema web desenvolvido para gestão e análise de cotações de fornecedores, com foco em apoio à tomada de decisão no processo de compras.

---

## 🚀 Sobre o Projeto

A **Central de Compras Inteligente** é uma aplicação que permite cadastrar, organizar e comparar propostas de fornecedores de forma estruturada, auxiliando na escolha da melhor opção com base em dados reais.

O sistema simula um ambiente corporativo de compras, aplicando conceitos de análise e apoio à decisão.

## ⚙️ Funcionalidades

- ✅ Login de usuário  
- ✅ Cadastro de fornecedores e preços  
- ✅ Inclusão de prazo e qualidade  
- ✅ Comparação automática de cotações  
- ✅ Ranking inteligente de fornecedores  
- ✅ Destaque do melhor fornecedor  
- ✅ Dashboard com indicadores  
- ✅ Cálculo de preço médio  
- ✅ Alerta de valores acima da média  
- ✅ Persistência de dados com LocalStorage  

---

## 🧠 Lógica de Decisão

O sistema avalia os fornecedores com base em três critérios principais:

- 💰 Preço  
- ⏱ Prazo  
- ⭐ Qualidade  

🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
